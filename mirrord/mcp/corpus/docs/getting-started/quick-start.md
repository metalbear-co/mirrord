# Quick Start

Get mirrord running against your cluster in a few minutes.

## Developers

1. [Install mirrord](install-mirrord.md): the CLI, or the extension for VS Code or a JetBrains IDE.
2. [Onboarding Wizard](onboarding-wizard.md) (optional): create your first mirrord config file.
3. [Starting your first session](first-session.md): run your local code in the context of the cluster.

## Platform teams

The Operator lets a team share a cluster and adds the Team and Enterprise features. [Install it](install-the-operator.md) once per cluster, with a [mirrord for Teams](what-is-mirrord.md#mirrord-for-teams) or [Enterprise](what-is-mirrord.md#enterprise-plan) license, or a 7-day trial.
