Added `target.tag_filter` and `target.jq_filter`, which select the task a serverless session attaches to by the tags of its AWS Batch job: a map of tag names to regexes, a jq program run on the tags, or both. mirrord waits for a matching task when none runs yet, and keeps the whole session on the task it attached to, so the session ends when that task ends. The filters need `operator: true` and an operator with serverless task selection.
