Fixed the local `mirrord ui` daemon never being disposed of. It outlives the session that starts it by design, but nothing ever stopped it: the only shutdown path was the manual `mirrord ui stop`, so a daemon stayed for the life of the machine and kept its own executable open. It now stops itself once it has had no sessions for 60 seconds, and a session that started one asks it to stop on the way out. That request is refused while any other session is tracked, so ending one session never takes the daemon from another. The internal proxy also no longer starts a daemon for a session that has no database branches, which is the only feature that uses it.
