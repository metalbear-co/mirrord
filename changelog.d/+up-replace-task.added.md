A task-driven `mirrord up` service can set `replace_task: true` to replace the AWS Batch jobs it matches with local processes: a matching job that turns on `MIRRORD_REMOTE_ADMISSION` doesn't run its own code, and ends with the exit code of the local process started for it, `128` plus the signal's number when a signal killed it, or `214` when the session was lost first, which includes stopping `mirrord up`. `replace_task` needs `target.tag_filter` or `target.jq_filter`.
