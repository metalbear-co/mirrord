The MySQL database branch examples in the config reference and CRD docs name version `8.4`. Any operator since 3.220.0 runs an `8.4` branch when asked; 3.232.0 makes it the default and loads `mysql_native_password` on it. On 3.220.0 to 3.231.0 a pinned `8.4` branch needs `--mysql-native-password=ON` in the `dbServerArgs` of a MySQL branch profile that only those branches select: the chart's top-level `dbServerArgs` reach every branch, and the unpinned ones run 8.0, which exits on that flag.
