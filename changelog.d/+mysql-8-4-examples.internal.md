The MySQL database branch examples in the config reference and CRD docs name version `8.4`. Any operator since 3.220.0 runs an `8.4` branch when asked; 3.232.0 makes it the default and loads `mysql_native_password` on it on the official `mysql` image. On 3.220.0 to 3.231.0 a pinned `8.4` branch needs `--loose-mysql-native-password=ON` in the chart's MySQL `dbServerArgs`; branches on 8.0 only log a warning for that flag.
