A `mirrord up` service with a serverless target can set `target.tag_filter` or `target.jq_filter` to run one local process for every task whose AWS Batch job tags match. Each process starts with its task's environment, and with the task's arguments appended to `run.command`, and it stops when its task ends. A process that exits doesn't stop the other services. These services need `common.operator: true`, run with `type: exec`, and can't be named by `--debug`.
