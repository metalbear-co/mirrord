`close()` on a remote file returns the error the target's filesystem reports on close, such as `ENOSPC` from a filesystem that writes data out on close, instead of always succeeding. This needs an agent from this release or later. With an older agent, `close()` keeps reporting success. `dup2()` or `dup3()` of a local file descriptor over one that refers to a remote file no longer leaves mirrord treating it as the remote file.
