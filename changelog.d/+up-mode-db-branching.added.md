Added `db_branching` to `mirrord-up.yaml` modes: `empty`, `schema` or `all` requests every `MirrordSplitConfig` DB branch with that copy mode, `inherit` with each entry's own, `off` none. An entry named `split`, `replace` or `mirror` may set it for that built-in mode. A custom mode without it requests no DB branches. In `mirrord.json`, `feature.db_branches` takes `{ "entries": "*", "copy": { "mode": "schema" } }` to request a copy mode.
