Added `db_branching` to `mirrord-up.yaml` modes: `empty`, `schema` or `all` requests every `MirrordSplitConfig` DB branch with that copy mode, `inherit` with each entry's own, `off` none. An entry named `split`, `replace` or `mirror` may set it for that built-in mode. A mode without it branches like the built-in mode its `incoming` names, and a mode without `queues` splits them like its `incoming`: mirrored with `incoming: mirror`, stolen otherwise. In `mirrord.json`, `feature.db_branches` takes `{ "entries": "*", "copy": { "mode": "schema" } }` to request a copy mode. `mirrord up` fails before starting any service when a mode's `db_branching` or `queues` line can't be served: no usable operator, no DB branch definitions, a copy mode outside an entry's `allowedModes`, or an operator that splits no queues.
