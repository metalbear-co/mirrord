Connect serverless agents and the CLI to the MetalBear Cloud sessions-manager at `https://sm-aws-use1.app.metalbear.com/sm` when neither the operator nor `MIRRORD_SESSIONS_MANAGER_URL` selects one, instead of failing. The CLI also takes the URL from the new `sessions_manager.url` config option, which `MIRRORD_SESSIONS_MANAGER_URL` overrides. Agents and the CLI log which sessions-manager they chose and why, without any credentials in its URL. `MIRRORD_SESSIONS_MANAGER_AUTH_TOKEN` without an explicit URL is an error, so a self-hosted proxy secret is never sent to MetalBear Cloud.
