Connect serverless agents and the CLI to the MetalBear Cloud sessions-manager at `https://sm-aws-use1.app.metalbear.com/sm` when neither the operator nor `MIRRORD_SESSIONS_MANAGER_URL` selects one, instead of failing. The CLI also takes the URL from the new `sessions_manager.url` config option, which `MIRRORD_SESSIONS_MANAGER_URL` overrides. Agents and the CLI log which sessions-manager they chose and why.
