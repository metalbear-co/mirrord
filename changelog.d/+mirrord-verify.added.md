Added `mirrord verify`, which runs a command and records on the cluster which commit was tested, which sessions the operator served for it and the traffic the operator routed to them. With `--checks`, the run passes only when the operator saw the listed traffic reach a session of the command. The operator signs each finished record, and `mirrord verify check` passes only for a commit with a signed record that says it passed. `mirrord verify show` prints the records, and `mirrord verify receipt` prints one as a pull request comment that can be checked without the cluster. It needs an operator that keeps verification records, and without `--checks` it runs the command without a record otherwise.
