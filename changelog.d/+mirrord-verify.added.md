Added `mirrord verify`, which runs a command and records on the cluster which commit was tested and which sessions the operator served for it. With `--checks`, the operator sends the listed requests itself into the sessions of the command and judges the answers. The operator signs each finished record, and `mirrord verify check` passes only for a commit with a signed record that says it passed. `mirrord verify show` prints the records. It needs an operator that keeps verification records, and without `--checks` it runs the command without a record otherwise.
