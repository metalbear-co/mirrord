Authenticate intproxies to a standalone sessions-manager with the developer's `mirrord login` token instead of the API-key exchange, which stays with agents. The CLI picks the token for the cloud set by `MIRRORD_METALBEAR_CLOUD_URL` (the latest login when there are several organizations) and hands it to the intproxy in its connect info, and warns when there is none. A sessions-manager reached through the operator is unaffected.
