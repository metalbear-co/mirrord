`mirrord subscribe` streams the events of one namespace by default, with or without `--key`: the one given with `-n/--namespace`, else `target.namespace` from the mirrord config, else the kubeconfig's default namespace. Pass `-A/--all-namespaces` to stream every namespace, which was the default before. The Events tab of `mirrord ui` gains a namespace picker, which starts at every namespace, and shows each event's namespace and target.
