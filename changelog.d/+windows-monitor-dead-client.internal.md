The Windows crash monitor no longer warns when a process goes away before it finishes registering. A program that exits during its own startup is ordinary, and the connection reset it leaves behind read as a fault, which made the warning worth ignoring. Those errors now log at debug and every other error keeps its warning. The per-process watcher also starts before the monitor acknowledges a registration, so a process that dies in between still gets its exit code recorded instead of sitting in the report tree with none.
