The TUI's Run view is three short steps: pick folders from anywhere on disk (projects under the home folder and folders used before are listed, and the disk can be browsed), pick targets (suggestions marked ★ sure or ☆ maybe, the sure ones already picked), then pick a config from a searchable list made from your picks (only my requests, branch databases, take over, no traffic) or found in your folders' `.mirrord` directory. Several folders run together as one session.
