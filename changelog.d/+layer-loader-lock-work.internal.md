The Windows layer no longer opens a socket inside `DllMain`: the mirrord-console logger moved to the worker thread that runs after `DllMain` returns, and `init_tracing` split into a loader-safe half and that one. The early process and module snapshot stays in `DllMain` on purpose, because a short-lived process exits before the worker runs and would otherwise record no snapshot at all. `layer-win` also gained a `clippy.toml` that rejects `std::thread::current`, `std::thread::park`, `std::io::stderr` and `std::io::stdout`, which all end the process when a hook reaches them.
