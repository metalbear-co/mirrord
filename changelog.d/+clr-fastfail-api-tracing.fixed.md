Fixed a .NET process under mirrord dying with a fast-fail (`0xC0000409`) when `MIRRORD_LOG` was set to trace on Windows. The `LoadLibraryW` and `GetProcAddress` detours log while a process shuts down, after the thread-local storage of that thread is gone, and the panic from that left the detour and ended the process. A detour must never unwind, so those log calls now contain their own panic.
