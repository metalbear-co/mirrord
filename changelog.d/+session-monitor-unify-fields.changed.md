`mirrord ui`'s session detail view now shows the same 8 fields, in the same order, under the same labels, for both your own sessions and sessions viewed on a shared operator: Key, Session ID, Port, Mode, Namespace, Container, HTTP filter, and Queue splits. A field with nothing to show renders as `—`; Queue splits shows "Requires higher tier" for a direct/OSS session, since queue splitting needs the mirrord Operator. Auto-generated keys are marked as such, and attached processes are listed, in your own session view only. Container is no longer blank for operator sessions whose target names one.
