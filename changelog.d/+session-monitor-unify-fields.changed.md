`mirrord ui`'s session detail view now describes a session the same way whether it is your own or a teammate's on a shared operator. Both views draw from the same ordered field list, `Key`, `Session ID`, `Port`, `Mode`, `Namespace`, `Container`, `HTTP filter` and `Queue splits`, so a field that has a value always appears under the same label in the same place. Fields with nothing to report are left out rather than printed as placeholders. On a direct session `Queue splits` reads `Requires higher tier`, since queue splitting needs the mirrord operator. Your own view also flags an auto-generated key and lists the processes attached to the session. `Container` no longer renders blank for an operator session whose target names one.
