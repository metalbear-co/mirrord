The agent now resolves the paths of remote file operations and outgoing unix socket connections strictly inside the target container's filesystem. Remote file operations no longer follow the magic links of `/proc` in any mode, including targetless, so reading a path such as `/proc/self/exe` or `/dev/stdin` remotely fails. A remote read now returns at most 1 MiB at a time, and a `feature.fs.readonly_file_buffer` larger than 1 MiB buffers only 1 MiB.
