Outgoing unix socket connections now reach sockets whose path in the target is too long for a socket address. In ephemeral mode, their paths now resolve in the target container's filesystem rather than the agent's. The `trustRoots` directories of a TLS steal config now load certificates that are absolute symlinks in the target, as most of `/etc/ssl/certs` is. The agent's DNS resolution now reads the target's `/etc/resolv.conf` and `/etc/hosts` when they're absolute symlinks, instead of the agent's files. Remote file operations relative to an open directory, with a path that leaves it such as `../file`, now resolve from where the directory is after it's renamed, rather than from its old path.
