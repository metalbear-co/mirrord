Fixed a Windows layer that fails to start being reported as a successful run. The layer installs every hook inside `DllMain`, before the target can run, and a failure there left only one line in the layer's own log: mirrord then ran the program with no interception at all and told the user nothing. The layer cannot report this itself, because reaching the crash monitor opens a socket, which must not happen under the loader lock, and the module unmaps as soon as it gives up. It now sets a named event that the waiting parent already holds, and the parent writes the crash report, which names the process and says its layer never started.
