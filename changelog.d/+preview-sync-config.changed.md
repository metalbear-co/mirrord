Changed the `sync` settings of `mirrord-up.yaml`: `sync.install` is now `sync.prepare`, its `on_change` is now `triggered_by`, and `sync.restart_on_change` is now `sync.run.restart`, which takes `on_prepare` (the default) or `on_sync`. `sync.run` no longer defaults to the service's `run.command`, so a service without it runs its image's own command, for example nginx serving the synced files. `sync.prepare.directory` no longer defaults to `sync.run.directory`. `mirrord preview sync` and `mirrord preview status` call a transfer of the local code a sync instead of a push, as in the status line `last sync 2m ago`.
