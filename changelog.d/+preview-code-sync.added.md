Added `mirrord preview sync`, which previews each service with `sync` in `mirrord-up.yaml` with your local code instead of a built image: the CLI pushes the `sync` directories into the preview pod, `install` installs the dependencies again when they change, and `--watch` keeps pushing your edits. A service runs its image from `--image` or `MIRRORD_<SERVICE>_IMAGE`, or the target's own image without one. `mirrord preview status` shows the sync of each session.
