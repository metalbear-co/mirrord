Released agent and CLI images and the released CLI binaries are now published with signed SLSA build provenance, so you can verify that what you pulled or downloaded was built by our release pipeline from this repository. Verify with `gh attestation verify oci://ghcr.io/metalbear-co/mirrord:<version> --owner metalbear-co`, or `gh attestation verify <binary> --owner metalbear-co` for a downloaded binary.
